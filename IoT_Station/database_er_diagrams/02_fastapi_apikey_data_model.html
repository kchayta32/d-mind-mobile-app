D-MIND · Security & Gateway Ingress Architecture

FastAPI Gateway · API Key Management & Client Application Data Model

แผนภาพสถาปัตยกรรมข้อมูลสำหรับจัดการ API Key บน FastAPI Gateway เพื่อให้แอปพลิเคชัน (Android Native App, Web Dashboard) นำคีย์ไปยืนยันตัวตนใช้งานอย่างปลอดภัย ครอบคลุมการแฮช SHA-256, การจำกัดอัตราเรียกใช้ (Rate Limiting), ขอบเขตสิทธิ์ (Scopes RBAC), บันทึกทราฟฟิก (Request Audit Logs) และการลงทะเบียนอุปกรณ์รับแจ้งเตือน (FCM Push Tokens)

API KEY STORAGE

Cryptographic SHA-256 Hashing

  • Zero Plaintext Storage: บันทึกเฉพาะค่า Hash SHA-256 ลงฐานข้อมูล คีย์ตัวจริงแสดงให้ผู้พัฒนาเห็นเพียงครั้งเดียวตอนสร้าง
  • Prefix Lookup: ใช้ key_prefix (เช่น dmind_live_a1B...) สำหรับการระบุตัวตนและ Logging โดยไม่เปิดเผย Secret
  • Fast Verification: สร้างดัชนี B-Tree บน hashed_key ทำให้คำขอแต่ละ Request ค้นหาและ Verify สิทธิ์ได้ในระดับ < 2ms

APPLICATION CONSUMPTION

Mobile Client Header Scheme

  • Header Support: รองรับทั้ง X-API-Key: dmind_live_xxxx และ Authorization: Bearer dmind_live_xxxx
  • Rate Limiting (120 RPM): ป้องกันการโจมตี Denial of Service (DoS) และจำกัดปริมาณโหลดจาก Mobile Client แต่ละตัว
  • Soft Revocation: ปิดการใช้งานทันทีผ่านฟิลด์ is_active = FALSE โดยไม่ต้องลบข้อมูลประวัติทิ้ง

SECURITY & COMPLIANCE

Ingress Audit & Push Dispatch

  • Traffic Audit Trail: ทุกคำขอบันทึก IP, User-Agent, รหัสสถานะ HTTP และ Latency ลงใน api_request_logs
  • Device Registration: เก็บโทเค็น device_push_tokens (FCM) เพื่อส่งข้อความ Broadcast เตือนภัยไปยังโทรศัพท์มือถือ
  • Row Level Security (RLS): ปกป้องตาราง api_keys ให้เฉพาะ Service Role เท่านั้นที่มีสิทธิ์จัดการ Full Access
