D-MIND · Comprehensive Architecture Model

D-MIND Platform · Unified Master Entity-Relationship Data Model

แผนภาพความสัมพันธ์ของข้อมูลแบบบูรณาการทั้งระบบ (Master Integrated Data Model) เชื่อมโยงสถานีตรวจวัดและโทรมาตรภาคสนาม (IoT Station), ระบบยืนยันสิทธิ์ Gateway (FastAPI API Keys), แอปพลิเคชันมือถือ (Android Client), ระบบกระจายข่าวเตือนภัยพิบัติฉุกเฉิน (Realtime Alerts & FCM Deliveries) ตลอดจนระบบแจ้งเหตุฉุกเฉินและขอความช่วยเหลือภาคประชาชน (Citizen SOS Reports)

IOT TO BACKEND ESCALATION

Real-time Telemetry to Alerts

  • Autonomous Triggering: ข้อมูลเซนเซอร์จาก sensor_logs ที่เกินระดับเกณฑ์ปลอดภัยจะยกระดับเข้าสู่ realtime_alerts อัตโนมัติ
  • Geofencing Coordination: มีพิกัด coordinates และ radius_km เพื่อกำหนดขอบเขตพื้นที่แจ้งเตือนไปยังผู้ประสบภัย
  • Offline Synchronization: บันทึกข้อความเตือนภัยและ Danger Zones แคชลง SQLite Room ในอุปกรณ์มือถือ

APPLICATION SECURITY

FastAPI Ingress Authentication

  • Unified Key Governance: แอปพลิเคชันทั้ง Mobile Android และ Web Admin ยืนยันสิทธิ์ผ่าน api_keys เดียวกัน
  • Zero Plaintext Storage: ใช้การแฮช SHA-256 ป้องกันการรั่วไหลของกุญแจในฐานข้อมูล
  • Rate Limit Defense: จำกัดอัตราเรียกใช้ (120 req/min) เพื่อป้องกันการโจมตี Denial of Service (DoS)

DISASTER RESPONSE & SOS

FCM Broadcast & Citizen Rescue

  • Targeted FCM Push: ระบบส่งต่อแจ้งเตือนไปยังอุปกรณ์เป้าหมายผ่าน alert_deliveries และ device_push_tokens
  • Citizen SOS Lifeline: ผู้ประสบภัยสามารถส่งคำขอความช่วยเหลือฉุกเฉินพร้อมพิกัด GPS เข้าตาราง victim_reports
  • End-to-End Traceability: ตรวจสอบสถานะการอ่านแจ้งเตือนและสถานะการช่วยเหลือได้แบบเรียลไทม์
