D-MIND DISASTER MONITORING SYSTEM · MASTER THESIS SPECIFICATION

IoT Station & Telemetry Subsystem · Entity-Relationship Landscape Model

Figure 3.4: แผนภาพความสัมพันธ์ของข้อมูลแบบแนวนอน (Horizontal Landscape Data Architecture) สำหรับประกอบเอกสารวิทยานิพนธ์ แสดงการแบ่งแยกเลเยอร์การทำงาน 4 ลำดับขั้น: 1) ระบบยืนยันสิทธิ์ Gateway (Ingress Auth), 2) บัฟเฟอร์กระแสข้อมูลหลัก (Master Stream Hub), 3) ตารางแยกย่อยเฉพาะมิติเซนเซอร์ผ่าน PostgreSQL Trigger (Domain Partitions), และ 4) กลไกประเมินและแจ้งเตือนภัยพิบัติอัตโนมัติ (Automated Alarm Engine)

TIER 1 & 2 · INGESTION ARCHITECTURE

Security & Ingestion Buffer

  • Zero-Trust Ingress: ควบคุมสิทธิ์การส่งข้อมูลด้วย api_keys ตรวจสอบค่า SHA-256 Hash และจำกัดอัตราคำขอ (120 RPM) ป้องกัน Flood Attack
  • Master Telemetry Stream: บันทึกค่าเซนเซอร์ทุกประเภทรวมใน sensor_logs แบบ Single Insert Transaction ลด I/O Overhead จากการเชื่อมต่อของ Gateway
  • Time-Series Indexing: เสริมประสิทธิภาพด้วย B-Tree Index บนคอลัมน์ timestamp DESC รองรับ Real-time Query บนแดชบอร์ดความเร็วสูง

TIER 3 · RELATIONAL DECOUPLING

Asynchronous Database Triggers

  • Trigger Function: sync_sensor_logs_to_individual_tables() กระจายข้อมูลลง 4 ตารางย่อยทันทีที่มีการ INSERT บน Master Table
  • Water Level Classification: จัดเกรดระดับน้ำอัตโนมัติ: ปลอดภัย (NORMAL), เฝ้าระวัง (WARNING ≥ 100 cm), วิกฤต (CRITICAL ≥ 140 cm)
  • Air Quality Index (AQI): คำนวณช่วงมลพิษฝุ่น PM2.5 จัดหมวดหมู่ aqi_category ช่วยให้โมบายแอปพลิเคชันคิวรีไปแสดงสีแจ้งเตือนได้ทันที
  • Seismic Vector Delta: คำนวณเวกเตอร์ความเร่งลัพธ์ $\|\sqrt{x^2+y^2+z^2} - 1.0g\|$ เพื่อตรวจจับแผ่นดินไหวและการทรุดตัวของโครงสร้าง

TIER 4 · DISASTER RESPONSE

Automated Anomaly Alerting

  • Evaluation Pipeline: เปรียบเทียบค่าโทรมาตรกับค่าวิกฤต (threshold_value) หากเกินเกณฑ์จะสร้างเรคคอร์ดใน disaster_alerts ทันที
  • Push Notification Broker: เชื่อมต่อกับ Firebase Cloud Messaging (FCM HTTP v1) บนโมบายแอปพลิเคชันเพื่อแจ้งเตือนภัยเร่งด่วนรายพื้นที่
  • State Audit & Resolution: บันทึกการคลี่คลายสถานการณ์ผ่าน is_resolved และ resolved_at เพื่อบันทึกเป็นสถิติภัยพิบัติย้อนหลัง
