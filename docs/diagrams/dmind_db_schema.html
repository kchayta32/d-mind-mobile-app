Database Schema · D-MIND System Architecture

D-MIND Mobile App · Physical Tables & Foreign Keys

ภาพรวมโครงสร้างตารางกายภาพ (Physical Schema) ของระบบ D-MIND Mobile App บน PostgreSQL / Supabase ครอบคลุมระบบศูนย์เตือนภัยเรียลไทม์ (Real-time Alerts), บันทึกการส่งแจ้งเตือนรายบุคคล (FCM Deliveries), รายงานเหตุฉุกเฉินจากประชาชน (Incident Reports) และการวิเคราะห์ภาพความเสียหายด้วย AI (Damage Assessments)

CORE ALERT SUBSYSTEM

Alerting & Notification Dispatch

  • realtime_alerts เป็นตารางศูนย์กลางในการกระจายข้อมูลเตือนภัย รองรับการผูกรัศมีพื้นที่ coordinates, radius_km และ severity_level
  • alert_deliveries เก็บสถานะการส่ง Push Notification (FCM) ระดับบุคคล โดยมีความสัมพันธ์แบบ ON DELETE CASCADE กับตารางเตือนภัยหลัก
  • รองรับการบันทึกผู้สร้างข้อมูลเตือนภัยผ่าน created_by เชื่อมโยง auth.users แบบ ON DELETE SET NULL

CITIZEN & AI INTEGRATION

Incident Reporting & Damage AI

  • incident_reports รองรับการแจ้งเหตุฉุกเฉินจากประชาชนผ่าน Mobile App โดยมีสถานะตรวจสอบ is_verified และพิกัด coordinates
  • damage_assessments เชื่อมโยงผลวิเคราะห์รูปภาพด้วย AI สู่เหตุการณ์จริง พร้อมค่าคะแนน confidence_score และประเมินมูลค่า estimated_cost
  • ความสัมพันธ์เชื่อมโยงผ่าน incident_id เมื่อลบรายงานเหตุการณ์ ข้อมูลผลวิเคราะห์ AI จะถูกลบตามแบบ CASCADE

SECURITY & COMPLIANCE

Identity & Schema Isolation

  • แยกโมดูลยืนยันตัวตนไว้ภายใต้ auth schema ของ Supabase พร้อมมาตรการควบคุมความปลอดภัยผ่าน Row Level Security (RLS)
  • คุ้มครองข้อมูลติดต่อผู้รายงานผ่านวิวสาธารณะ incident_reports_public เพื่อป้องกันข้อมูลส่วนบุคคลรั่วไหล
  • ดัชนีคีย์หลัก idx_alerts_is_active และ idx_deliveries_alert_user รองรับการประมวลผลคำขอปริมาณสูงได้อย่างรวดเร็ว
